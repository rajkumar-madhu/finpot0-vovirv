Place voice prompt WAV files here for IndicF5 TTS.

File naming convention:
  {LANG}_{GENDER}_{EMOTION}_{ID}.wav

Examples:
  TAM_F_HAPPY_00001.wav  — Tamil, Female, Happy
  ENG_M_NEUTRAL_00001.wav — English, Male, Neutral
  HIN_F_HAPPY_00001.wav  — Hindi, Female, Happy

Supported languages: ENG, TAM, HIN, TEL, KAN, MAL, BEN, GUJ, MAR, PUN, ORI

Each prompt should be 3-10 seconds of clear speech for voice cloning reference.
